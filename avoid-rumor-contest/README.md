# 古都谣言净化录 - H5互动游戏

## 项目简介

《古都谣言净化录》是一款基于HTML5的互动游戏，主题为"古都新风·辟谣同行"。玩家扮演"网络清风侠"，在西安地标场景中点击清除谣言气泡，净化网络环境。

## 功能特色

### 🎮 核心玩法
- **场景净化**：在4个西安地标场景中净化谣言
- **气泡交互**：点击飘动的谣言气泡了解真相
- **进度追踪**：实时显示净化进度和统计信息
- **场景解锁**：完成当前场景70%净化即可解锁下一场景

### 🏛️ 场景设置
1. **大雁塔** - 千年古塔，见证历史
2. **钟楼** - 古城中心，钟声悠扬  
3. **回民街** - 美食天堂，文化交融
4. **陕西历史博物馆** - 文物宝库，历史长河

### 🎨 视觉设计
- 响应式设计，完美适配移动端
- 古风色彩搭配，体现西安古都特色
- 流畅的动画效果和粒子特效
- 场景从污染状态到净化状态的视觉过渡

### 📱 技术特性
- 纯HTML5+CSS3+JavaScript实现
- 支持微信内置浏览器
- 移动端触摸优化
- 性能优化，流畅运行

## 使用方法

### 1. 直接运行
1. 将所有文件放在同一目录下
2. 用浏览器打开 `index.html`
3. 点击"开始游戏"即可体验

### 2. 本地服务器运行
```bash
# 使用Python简单服务器
python -m http.server 8000

# 或使用Node.js
npx http-server

# 然后访问 http://localhost:8000
```

### 3. 部署到服务器
将所有文件上传到Web服务器即可，支持任何静态文件托管服务。

## 游戏操作

### 基本操作
- **点击气泡**：点击飘动的谣言气泡查看真相
- **场景切换**：使用左右箭头按钮切换场景
- **音效控制**：点击右上角音效按钮开关音效

### 键盘快捷键
- `空格键`：暂停/恢复游戏
- `ESC`：暂停游戏
- `←/→`：切换场景

## 自定义配置

### 添加新谣言
编辑 `data/rumors.json` 文件，按照以下格式添加：

```json
{
  "id": 16,
  "text": "新的谣言内容",
  "truth": "对应的真相说明",
  "type": "谣言类型",
  "scene": "场景ID"
}
```

### 修改场景配置
编辑 `data/scenes.json` 文件：

```json
{
  "id": "新场景ID",
  "name": "场景名称",
  "image": "背景图片文件名",
  "description": "场景描述",
  "unlockProgress": 70,
  "bubbleCount": 4
}
```

### 调整游戏参数
编辑 `data/config.json` 文件：

```json
{
  "bubble": {
    "maxBubbles": 8,        // 最大气泡数量
    "spawnInterval": 2000,  // 气泡生成间隔(毫秒)
    "floatDuration": 10000  // 气泡浮动时长(毫秒)
  },
  "scene": {
    "unlockThreshold": 70   // 场景解锁阈值(百分比)
  }
}
```

## 开发说明

### 核心类说明
- `GameEngine`：游戏引擎核心，管理游戏状态和逻辑
- `SceneManager`：场景管理器，处理场景切换和状态
- `BubbleManager`：气泡管理器，控制气泡生成和动画
- `Bubble`：单个气泡类，处理气泡行为和交互

### 扩展开发
如需添加新功能，可以：
1. 在相应的类中添加新方法
2. 在 `data/config.json` 中添加配置项
3. 在 `data/rumors.json` 中添加新谣言数据
4. 在 `data/scenes.json` 中添加新场景

## 注意事项

1. **图片资源**：确保背景图片文件存在于项目根目录
2. **数据格式**：JSON文件必须符合指定格式，否则可能导致加载失败
3. **浏览器支持**：建议使用现代浏览器以获得最佳体验
4. **移动端**：在移动设备上建议竖屏模式使用
