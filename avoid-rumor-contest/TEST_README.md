# 古都谣言净化录 - 单元测试

## 测试概述

本项目包含了完整的单元测试，用于验证游戏引擎和气泡管理器的核心功能。测试可以在不打开浏览器的情况下运行，确保代码质量。

## 运行测试

### 方法1：使用Node.js运行测试脚本

```bash
# 确保已安装Node.js (版本 >= 12.0.0)
node run-tests.js
```

### 方法2：使用npm脚本

```bash
# 运行测试
npm test

# 启动开发服务器
npm start
```

## 添加新测试

要添加新的测试用例，请编辑 `tests/game-engine.test.js` 文件：

1. 在相应的测试类中添加新的测试方法
2. 使用 `this.runTest()` 方法包装测试逻辑
3. 使用 `this.assert()` 方法进行断言
4. 在 `runAllTests()` 方法中调用新测试

### 示例：

```javascript
async testNewFeature() {
    this.runTest('新功能测试', async () => {
        // 测试逻辑
        const result = someFunction();
        
        // 断言
        this.assert(result === expected, '结果应该符合预期');
    });
}
```

## 故障排除

### 常见问题

1. **Node.js版本过低**
   - 确保Node.js版本 >= 12.0.0
   - 运行 `node --version` 检查版本

2. **测试失败**
   - 检查控制台输出的错误信息
   - 确保所有依赖文件存在
   - 验证测试逻辑是否正确

3. **文件路径问题**
   - 确保在项目根目录运行测试
   - 检查文件路径是否正确

## 贡献指南

1. 在修改代码后运行测试确保没有破坏现有功能
2. 为新功能添加相应的测试用例
3. 确保所有测试通过后再提交代码
4. 保持测试代码的可读性和可维护性
